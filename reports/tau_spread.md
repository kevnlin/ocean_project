# DFS evidence spread on real Argo input

_Generated by `experiments/59_tau_spread.py`. Untrained weights at a fixed seed: tau is a property of the observations and the encoder, so a trained checkpoint would only confound it with what a run learned._

`tau` is the per-token evidence mass. Where it is flat, DFS and Uniform are computing nearly the same thing and any null between them is arithmetic rather than empirical.

**Reading it.** A CV near zero means the estimator finds the observations nearly independent, so it has almost nothing to downweight — DFS ≈ Uniform follows by construction and says nothing about whether evidence weighting helps when redundancy is present. A large spread means the mechanism is active, and a null in the accuracy tables under those conditions is a real negative result about the mechanism rather than an artefact of the input density.
