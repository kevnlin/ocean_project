# 多模态海洋重建：完整架构与本轮实测结论

日期：2026-10-07。**本轮注册的 backbone 比较、架构实现与完整实验已完成：24 次训练全部达到 6000 步，随后完成 21 次冻结模型的 2022–2023 开发集评估。** 结果支持在强卫星初猜加逐层 OI 基线上增加神经修正与不确定性头；同时，严格组件消融尚未支持“共享 latent 本身是精度提升所必需”的结论。

按预先登记、仅使用 2021 验证集的规则，最终选择 **Soft MoE large 的三种子集成**。其开发集温度/盐度 J 为 **0.616304 / 0.750930**，相对本轮匹配 anchor 的 RMSE 分别降低 **1.12% / 0.99%**。这是本协议下的实测提升，尚不能据此宣称跨论文 SOTA。

本报告依据已保存的 完整比较数据 (`outputs/latent_ocean/comparison_20261007.json`)、组件配对差值 (`outputs/latent_ocean/component_contrasts_20261007.json`)、验证集最终选择 (`outputs/latent_ocean/final_selection_20261007.json`)、运行完成记录 (`outputs/latent_ocean/full_campaign_status_20261007.json`) 和 分组诊断数据 (`outputs/latent_ocean/generalization_20261007.json`)。方法、公式与注册矩阵见 [架构和实验协议](latent_architecture_protocol_20261007.md)。

发布说明：下文记录的 `outputs/latent_ocean/` JSON、权重和预测属于运行时产物，未包含在本次 GitHub 源码快照；保留文件名用于说明历史证据来源。报告中的数值和完成状态保持原始记录。

## 1. 我们的目标与实际 backbone

长期目标是从卫星 SST、SSS、SLA 和稀疏 Argo 温盐剖面学习一个共享三维海洋状态，按位置、深度和日期查询温度、盐度及不确定性。本轮完成的是回顾性重建的研究管线：目标浮标不给出温盐值，上下文来自同月其他浮标；当前完整推理和评估只覆盖 20 个既定深度层。

实际 backbone 为 **逐深度观测编码器 → 共享 latent Transformer → 独立查询解码器**，并保留已有逐层 OI 分析和新增的未压缩数值新息局部通路。

| 组件 | 实际实现与作用 |
| --- | --- |
| 固定卫星初猜 | 已保存的 56 → 512 → 512 → 512 → 40 MLP；56 维特征包含位置/周期时间、月 SST/SSS/SLA 与有效性、日 SLA 及其差分。输出 20 层 × T/S；训练预测采用按年份 cross-fit 缓存。 |
| Argo 观测编码器 | 每个实际深度层生成 token：62 维外部特征、坐标编码，以及该层独立的 T/S 数值新息与有效性。保留报告误差及其缺失标记，未将剖面压成深度带均值。 |
| 表面 token | 在上下文剖面位置采样同一套 56 维卫星位置特征；当前没有完整卫星栅格编码器。 |
| 坐标与模态 | 42 维球面/Fourier、线性与对数深度、周期日期编码；Argo 与表面 token 使用独立投影和模态表示。活跃模态使用等总量 attention prior，并保留 null token。 |
| 共享 latent | 可学习 latent 配合球面与深度锚点；每层执行观测 cross-attention、latent self-attention、FFN 或 Soft MoE。large 为宽度 192、96 个 latent、6 个 block、4 heads，上下文最多 768 条剖面的 20 层 token。 |
| 原始 OI 分析 | 每查询从完整来源池选 32 条空间近邻，按同层新息、日期与 SLA 状态构建核并用 float64 解线性系统；共 200 个参数。默认模型继续训练这些参数；机制消融全部冻结。 |
| 独立查询 decoder | 查询外部特征 58 维；2 层 query-to-latent cross-attention。目标查询之间没有 self-attention，查询顺序或分块不应改变预测。 |
| 新数值新息局部通路 | 66 维邻居外部特征加偏移、新息及有效性；学习插值权重、null/background 权重与门控，直接使用逐层数值新息。检索来自完整来源池，不受 latent 剖面预算限制。 |
| T/S 均值与尺度头 | 共享表示后分别输出温盐残差及高斯尺度；尺度限制在标准化异常值的 0.03–3.0。残差和局部门控零初始化，初始均值严格等于匹配 OI anchor。 |

均值由已有 OI 结果、共享表示的残差和局部新息门控修正共同组成。这里的“精确数值新息”指直接保留测量对应的新息数值，不代表硬性通过每个观测点，也不代表共享 latent 是解析 Kalman 或贝叶斯后验。

| 已实现并训练的路线 | base 神经参数 | large 神经参数 | 方法差异 |
| --- | ---: | ---: | --- |
| Dense latent Transformer | 1,506,838 | 4,386,840 | latent 使用普通 FFN。 |
| Soft MoE latent Transformer | 2,696,730 | 13,727,262 | 替换 latent FFN；large 使用 8 专家 × 2 slots，连续 dispatch/combine，所有专家均执行。 |
| Local Transformer + latent | 1,738,774 | 4,906,776 | 保留 Dense latent，在每查询的 32 邻居集合内增加局部 Transformer。 |

表中不含固定初猜的 575,016 个参数及 200 个 OI 参数。Soft MoE 不是 top-k 稀疏路由，当前结果不证明计算加速或专家自然对应海区。各路线 base/large 同时改变宽度、latent 数、层数和上下文预算，不能将差值解释成单独一个组件的收益。

## 2. 完成了哪些实验与校验

| 阶段 | 完成数 | 规则 |
| --- | ---: | --- |
| 架构搜索 | 7 次 × 6000 步 | 三类架构各 base/large、种子 1234，加 OI-only；全部完成后仅按验证集选各路线 capacity，三条路线均选 large。 |
| 多种子复现 | 8 次 × 6000 步 | 三个冻结 large 配置与 OI-only 各增加 1235、1236，形成四组 3 种子。 |
| 固定 OI 组件控制 | 9 次 × 6000 步 | 按单模型验证结果选定 Dense large，完整网络、关闭 latent、关闭新增局部通路各 3 种子；三组 OI 均冻结。 |
| 冻结开发评估 | 21 次 | 四组主配置 × 3 种子及九个控制模型；未选中的 base 不在开发集上寻找替代选择。 |

训练共 144,000 个优化步骤。每次训练均完成 6000 步，实际评分使用该次训练由验证集选出的最佳 checkpoint，因此最佳步数可以小于 6000。训练年份 2016–2020，验证年份 2021，开发年份 2022–2023。每步随机选月并按 WMO 整体隐藏约 30% 上下文浮标作为目标，再抽 1024 个深度查询；目标与来源浮标不重叠。每 500 步固定验证一次，初始化 step 0 也参与最佳模型比较。

损失为温盐等权有效均值的 MSE + 0.02 × Gaussian NLL。AdamW 的神经学习率为 3×10⁻⁴、weight decay 0.01；可训练 OI 学习率为 10⁻³、不加 weight decay。warmup 300 步后 cosine 降至初始学习率的 10%，梯度裁剪 1；CUDA 神经计算采用 bf16，OI 解采用 float64。卫星输入、初猜缓存、完整局部来源池和评分身份始终匹配。

CPU 完整测试结果为 **725 项通过、5 项跳过**；其中 4 项依赖未提供的外部 GODAS 数据，一项 CUDA 测试在 CPU 沙箱中跳过。该 CUDA 续训回归已另行在真实 GPU 上通过：验证了 bf16 模型、OI、AdamW、cosine 调度器、CPU/CUDA/NumPy 随机状态、最佳 checkpoint 和预测数组的严格重放。见 GPU 续训验证记录 (`outputs/latent_ocean/cuda_resume_validation_20261007.json`)。这些校验支持实现与复现可靠性，不构成科学效果的独立确认。

独立产物审计核对了 24 次训练最后历史记录均为 6000 步；21 份开发预测的 `month/profile/level/target/baseline` 五项评分身份逐元素一致，观测、特征、场景和训练/评估源代码指纹匹配。九个固定 OI 模型的 best/last 共 18 个 checkpoint 中，OI tensor 均与原始 anchor 完全相等；规则登记与最终验证选择均早于首次开发评估。组件分析已从保存预测重放，分数和全部 bootstrap 区间逐项一致。见 最终核验清单 (`outputs/latent_ocean/final_integrity_20261007.json`)。

## 3. 精度：种子统计与集成分数分别报告

J = 模型标准化异常值 RMSE / 同一变量、同一评分集合的零异常预测标准化 RMSE，越低越好；`macro_z` 是温度和盐度标准化 RMSE 的等权平均，并非两种 J 的平均值。开发集每变量均有 **976,452** 个有效温盐评分值；验证集每变量有 **87,356** 个。

匹配 anchor 是 `anc_satday_dfs` 保存初猜与 `anc_satday_kriging` 保存 OI 参数在本轮场景上的重新组合。应与本轮重新计算的 anchor 比较，而不是直接减去历史约 0.623 的结果。

### 3.1 开发集：三次独立训练的均值 ± 样本标准差

| 方法 | 温度 J ↓ | 盐度 J ↓ |
| --- | ---: | ---: |
| 匹配 anchor（固定单一模型） | 0.623260 | 0.758456 |
| OI-only 继续训练 | 0.622972 ± 0.000024 | 0.758649 ± 0.000075 |
| Dense latent · large | 0.616863 ± 0.000491 | 0.751170 ± 0.000193 |
| Soft MoE latent · large（验证集选中） | 0.616900 ± 0.000635 | 0.751532 ± 0.000384 |
| Local Transformer + latent · large | 0.617002 ± 0.000330 | 0.751918 ± 0.001183 |

这里的标准差只描述种子 1234、1235、1236 三次训练的变化，不是按观测数得到的误差条，也不是集成预测的标准差。

### 3.2 开发集：先平均三种子预测，再计算分数

| 方法 | 温度集成 J ↓ | 盐度集成 J ↓ | 开发集 macro_z ↓ | 2021 验证集集成 macro_z ↓ |
| --- | ---: | ---: | ---: | ---: |
| 匹配 anchor | 0.623260 | 0.758456 | 0.763954 | — |
| OI-only 继续训练 | 0.622954 | 0.758632 | 0.763892 | 0.676438 |
| Dense latent · large | 0.616286 | 0.750596 | 0.755763 | 0.669073 |
| Soft MoE latent · large（验证集选中） | 0.616304 | 0.750930 | 0.755964 | 0.668756 |
| Local Transformer + latent · large | 0.616102 | 0.751095 | 0.755951 | 0.669698 |

最终选择规则在开发评估开始之前注册，并于 **2026-10-07 10:14:02 UTC** 使用 2021 验证集执行。七个三种子候选（四主配置及三个固定 OI 控制）中，Soft MoE 的验证集集成 `macro_z=0.668756` 最低，因此最终推荐该模型。Dense 的开发集总体均值误差略低，Local Transformer 的开发集温度最低；这两个后验观察不能用来更换已冻结的最终选择。Dense 约有 Soft MoE 三分之一的神经参数，适合保留为性能接近的成本参照，当前选择规则没有将参数成本当成筛选阈值。

OI-only 继续训练只带来微小温度改善，盐度略有退化；其总体差值区间包含零。主模型的改进不能仅用继续训练 200 个 OI 参数解释。

### 3.3 Soft MoE 集成相对匹配 anchor 的配对区间

| 指标 | 开发集差值：模型 − anchor | 95% 配对整月 bootstrap 区间 |
| --- | ---: | --- |
| 温度 ΔJ | -0.006956 | [-0.007894, -0.006050] |
| 盐度 ΔJ | -0.007526 | [-0.011478, -0.004362] |
| Δmacro_z | -0.007991 | [-0.009869, -0.006509] |

使用 2022–2023 的 24 个完整日历月作为配对重采样单位，4000 次抽样；负值表示改进。该区间支持这 24 个月内对匹配 anchor 的平均改善，不覆盖训练种子不确定性、更长周期相关性或开发数据曾被使用的选择偏差。

## 4. 不确定性：明显改善，中央区间仍偏保守

基线高斯尺度按变量和深度仅用 2021 验证残差 RMS 拟合，再冻结用于开发集。神经模型尺度由训练损失学习；集成尺度采用总方差公式 `mean(sigma² + mu²) − ensemble_mu²`，包含种子间均值差异。以下 NLL 基于标准化异常值，不能当作物理单位下的绝对 NLL。

| 方法 | 温度 NLL ↓ | 盐度 NLL ↓ | 温度 68% / 95% 覆盖 | 盐度 68% / 95% 覆盖 |
| --- | ---: | ---: | ---: | ---: |
| 匹配 anchor + 验证集尺度校准 | 1.005345 | 1.294639 | 79.55% / 94.37% | 80.91% / 94.95% |
| OI-only 继续训练集成 | 1.017969 | 1.446817 | 77.30% / 93.34% | 75.81% / 92.52% |
| Dense latent · large集成 | 0.737070 | 0.916431 | 74.76% / 95.24% | 75.33% / 95.24% |
| Soft MoE latent · large（验证集选中）集成 | 0.738924 | 0.847529 | 74.63% / 95.19% | 75.23% / 95.17% |
| Local Transformer + latent · large集成 | 0.736677 | 0.945884 | 75.34% / 95.51% | 74.78% / 95.00% |

OI-only 没有训练神经尺度头，表中仍使用初始 0.6 尺度及种子均值分散产生的总方差，不能将其当成已充分优化的概率基线。Soft MoE 的温盐 95% 覆盖约为 95.19% / 95.17%，接近名义覆盖；68% 覆盖为 74.63% / 75.23%，中央区间仍偏宽。因此可以说其开发集 NLL 和校准表现改善，不能说不确定性已经完全校准。

## 5. 固定 OI 消融：局部数值通路有效，共享 latent 必要性未得到支持

机制消融使用搜索阶段按单模型验证结果冻结的 **Dense large**，全部以相同 OI 参数、卫星、初猜、来源池和评分点运行。下表是每组三种子集成；“关闭新增局部通路”仍保留原始逐层 OI，“关闭 latent”仍保留 query MLP 残差与局部数值通路。此结果直接约束 Dense 组件归因，不能自动推广为 Soft MoE 组件的已证实结论。

| 固定 OI 控制 | 温度集成 J ↓ | 盐度集成 J ↓ | 温度 / 盐度 NLL ↓ |
| --- | ---: | ---: | ---: |
| 完整网络 | 0.617543 | 0.751890 | 0.739523 / 0.905942 |
| 关闭共享 latent | 0.617075 | 0.751528 | 0.737619 / 0.918955 |
| 关闭新增局部通路 | 0.621126 | 0.755952 | 0.790944 / 1.041284 |

| 配对差值：完整网络 − 关闭组件 | 温度 ΔJ［95% 整月区间］ | 盐度 ΔJ［95% 整月区间］ |
| --- | --- | --- |
| 共享 latent 的增量 | +0.000468 [+0.000131, +0.000825] | +0.000362 [-0.000090, +0.000725] |
| 新增局部通路的增量 | -0.003583 [-0.004226, -0.002988] | -0.004062 [-0.005573, -0.003140] |

共享 latent 的温度精度增量为正，且区间完全大于零，即在此固定 OI 的 Dense 对照中加入 latent 反而使温度略差；盐度均值也略差，但区间包含零。完整网络盐度 NLL 优于无 latent 控制，提示表示仍可能对概率建模有帮助，不过当前数据不足以证明共享 latent 是最终精度所必需。新增局部数值通路则使温盐 J 与 NLL 都改善，温盐 ΔJ 区间均完全小于零。研究贡献必须围绕已证明的局部新息收益与整体建模结果展开，不能把所有提升归因于共享 latent。

## 7. 可以保留的结论与研究边界

可以保留的实测结论是：在固定卫星产品、初猜、来源剖面和评分集合的条件下，三类新增神经路线均取得稳定但约 1% 量级的温盐 RMSE 改善，Soft MoE 集成被验证集规则选中；神经尺度头及集成使开发集 NLL 明显改善。固定 OI 的 Dense 消融支持新增数值新息局部通路，尚未支持共享 latent 的精度必要性。

以下内容仍未得到本轮证据支持：

- **跨论文 SOTA：** 缺少同输入、同产品时间可得性、同评分集合的外部先进方法比较；历史 SetConv/LNO/D4RT 输入不完全一致，不能据此构造公平 SOTA 排名。
- **独立泛化确认：** 2022–2023 之前已经用于开发，当前不能改名为独立 test；纬度/季节/距离切片也没有建立新的独立 OOD 数据集。
- **完整任意深度重建：** 解码器读连续坐标，但初猜与新息选择仍依赖 20 层索引；已验证的是 5–984.7 m 的 20 个固定层，完整任意深度推理尚未完成。
- **因果预报：** 同月上下文可能晚于查询日期。当前结果属于重建；预报必须单独限制观测与卫星产品的时间可得性。
- **独立多模态信息量与证据一致性：** SST/SSS L4 分析可能使用原位数据，Argo 证据可能经产品回流；匹配产品的方法比较仍成立，但不能宣称排除了被隐藏 Argo 经卫星分析产品复用的影响。当前没有来源相关的精确后验、条件信息增量估计、重复记录不变性或硬性测量一致性证明。
- **完全未见浮标：** 温盐归一化沿用所有训练年份剖面，包含被全局划为 heldout 的训练 WMO；没有使用验证/开发年份温盐拟合归一化，但不能说 heldout WMO 从未参与任何预处理。

模型架构采用既有输入—latent—query 和 Soft MoE 方法；Transformer、MoE 或“卫星 + Argo”本身不能作为新颖性主张。当前可以研究的贡献是未压缩逐层数值新息与共享表示的组合、局部证据修正和概率建模，并以本轮负结果限制对共享状态机制的宣传。
