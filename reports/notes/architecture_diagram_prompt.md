# Architecture diagram — the accurate figure, and a prompt for an image model

**Use `reports/real_data/fig_architecture.png` (and `.svg`) in the deck and the
paper.** It is generated by `experiments/real_data/64_architecture_figure.py`, so
every label is the current pipeline and every annotation is a number the audit
measured. Regenerate it after any pipeline change rather than editing the image.

A generative image model (Imagen, "Nano Banana" / Gemini image) cannot be trusted
with a technical diagram: it renders plausible-looking but wrong text, invents
boxes, and cannot be regenerated consistently when a number changes. What it is
good for is a **stylised opening illustration** — the kind of picture that sits on
slide 1 next to the title, not the figure a reviewer reads. The prompt below is
for that, and there is no image-model key configured on this machine, so it has
not been run here.

## Prompt (stylised opener, not the technical figure)

> A clean, modern scientific illustration for a machine-learning paper about
> reconstructing the three-dimensional ocean from sparse floats. Left third: a
> cutaway wedge of ocean seen from slightly above, deep navy fading to pale blue
> with depth, with about a dozen small white Argo float symbols scattered near the
> surface and thin vertical dotted lines descending from each to about two-thirds
> of the depth, showing where each float measured. Middle third: those dotted
> measurement lines converging into a soft, glowing lattice of small rounded
> rectangles — an abstract neural representation — in warm amber against the cool
> blues. Right third: the lattice expanding back out into a smooth, continuous
> three-dimensional temperature field rendered as translucent horizontal layers in
> a blue-to-orange gradient, with one small crosshair marking a single query point
> inside the volume. Flat vector style, no text, no labels, no logos, generous
> white space, muted palette of deep navy, mid blue, teal and amber on an off-white
> background, subtle depth shading, 16:9.

Negative prompt: `text, letters, numbers, labels, watermark, logo, photorealism,
busy background, neon, lens flare, 3-D chrome, clip-art fish`

**Checks before using any generated image:** it must contain no text (models
garble it), the float symbols must sit at the surface rather than mid-water, and
the depth gradient must go dark with depth, not light. If the model insists on
labels, generate at 16:9 and crop them out.

## If you want the technical figure restyled instead

Ask for an SVG edit, not an image generation: the diagram script writes
`fig_architecture.svg`, which opens in Illustrator, Inkscape or Figma with every
box and label as an editable object. Colours come from
`src/ocean_tokenizer/plot_style.py`, so changing the palette in one place restyles
every figure in the repo at once.
